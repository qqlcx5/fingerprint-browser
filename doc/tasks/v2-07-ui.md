# V2-07 电商运营界面

> 目标：提供 12 店铺场景下可扫描、可批量操作且不暴露敏感数据的桌面界面。
> 依赖：V2-01；创建/编辑和真实联调依赖 V2-06。可先以 API mock 完成布局。
> 可写路径：`src/renderer/src/**`、`doc/tasks/v2-07-ui.md`
> 禁止：修改主进程、preload、共享类型和依赖文件。

## 任务清单

- [x] T1 调整环境列表：展示站点、店铺标识、角色、代理出口 IP/国家、验证时间、运行状态与安全待办；支持站点 -> 店铺分组及多条件搜索。
- [ ] T2 重做创建/编辑环境表单：创建环境已强制代理预检，并展示站点/国家不一致提示；代理出口 IP 冲突和独立重绑定确认界面仍待实现。
- [ ] T3 实现 CSV 代理导入工作流：文件选择 -> 行级校验 -> 预检结果 -> 冲突筛选 -> 批量分配确认；界面不显示代理密码。
- [x] T4 实现账号安全面板：记录 2SV、手机号、登录提醒、未知设备清理和重新验证待办；TOTP 功能默认隐藏，启用/读取/清除均有高风险确认，动态码不自动复制。
- [ ] T5 补环境详情、审计查看、删除/清除确认、错误文案与桌面人工验收；覆盖 12 环境列表不溢出、不遮挡和键盘可操作。

## 验收

- 操作者可在一个列表中辨认 12 个环境的店铺、出口和安全状态。
- 代理预检失败、IP 冲突、出口变化与安全存储不可用均有明确可行动提示。
- 界面不渲染密码、TOTP 密钥、恢复码、Cookie 或日志中的敏感字段。
