# V2-08 集成、质量与发布

> 目标：在真实桌面环境验证 V2 约束，并交付可安装、可诊断的版本。
> 依赖：V2-01 至 V2-07。
> 可写路径：`scripts/**`、`build/**`、`resources/**`、`electron-builder.yml`、`doc/tasks/v2-08-quality.md`
> 协调者可额外修改：`src/main/index.ts` 仅用于模块接线。
> 禁止：修改各业务模块逻辑；发现问题按模块回派。

## 任务清单

- [ ] T1 集成所有 V2 IPC 与模块初始化，执行 `pnpm typecheck`、`pnpm lint`、`pnpm build` 和现有 E2E 冒烟；记录版本和运行环境。
- [ ] T2 增加 V2 集成测试：旧库迁移、出口 IP 唯一性、IP 变化启动阻断、重绑定审计、CSV 预检、敏感数据不导出、TOTP 生命周期。
- [ ] T3 真实代理回归：HTTP、HTTPS、SOCKS5 认证各至少一条；验证出口检测、固定 IP 比对与错误分类。不得使用真实店铺凭据作为测试数据。
- [ ] T4 在 32GB 基准设备执行 12 环境、30 分钟稳定性采样，记录整机物理内存、CPU、启动时延、崩溃和 Profile 串用结果。
- [ ] T5 完成 Windows x64 与 macOS arm64 安装/卸载、升级、数据保留和删除环境的人工验收；输出发布说明、已知限制和回滚方案。

## 验收

- V2 全部自动化测试、静态检查和生产构建通过。
- 12 环境稳定性数据满足 PRD 或明确记录为发布阻塞项。
- 安装包不包含测试秘密；用户数据、代理凭据和可选 TOTP 密钥遵守删除/保留语义。
