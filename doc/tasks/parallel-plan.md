# V2 多 Agent 执行计划

> 适用范围：`doc/tasks/v2-*.md`。旧版 `01-09` 任务是已完成的历史记录，不得回填或覆盖。
> 模式：同一工作目录可并行，但每个 Agent 只能写其任务文件声明的白名单路径。

## 1. 执行阶段

| 阶段 | 任务 | 执行方式 | 前置条件 |
| --- | --- | --- | --- |
| A | V2-01 契约与迁移协调 | 串行，协调者 | 无 |
| B | V2-02 存储、V2-03 代理、V2-04 安全、V2-05 Profile | 先 02，后 03；04 与 05 可并行 | V2-01；V2-03 还依赖 V2-02 |
| C | V2-06 环境编排 | 串行 | V2-02 至 V2-05 |
| D | V2-07 界面 | 可在 V2-01 后用 mock 开始；真实联调在 V2-06 后 | V2-01 / V2-06 |
| E | V2-08 集成、质量与发布 | 串行 | V2-01 至 V2-07 |

## 2. 共享文件规则

以下文件由协调者独占，其他 Agent 只读：

- `src/shared/types.ts`
- `src/shared/paths.ts`
- `src/main/ipc.ts`
- `src/preload/**`
- `src/main/index.ts`
- `package.json`、锁文件和构建配置
- `doc/tasks/progress.md`

任务需要改动这些文件时，Agent 必须停止并记录：`需要协调：文件、字段/通道、原因、下游影响`。协调者完成 V2-01 或集成接线后再继续。

## 3. Agent 提示词

```text
你在执行 doc/tasks/v2-XX-<module>.md。
先读本任务文件和 doc/tasks/parallel-plan.md。
只允许写任务文件声明的“可写路径”；共享文件一律只读。
禁止执行 git、依赖安装、打包、开发服务器；允许运行与本模块相关的 typecheck 或测试。
按 T1 到 T5 顺序完成，每完成一个任务立刻在本模块 md 中勾选并记录验证命令与结果。
需要共享契约或发现其他模块缺陷时，停止并写：需要协调：<文件/原因/建议>。
不要修改 doc/tasks/progress.md。
```

## 4. 集成规则

1. 只有协调者修改 `progress.md`，在模块的所有 T 任务和验收通过后将模块标为完成。
2. 只有协调者接入 `src/main/index.ts`、新增依赖、运行全仓 build 和处理跨模块冲突。
3. 每次集成先运行 `pnpm typecheck`，再运行 `pnpm lint`、`pnpm build` 和相关 E2E；失败回派到责任模块，不在集成阶段顺手改业务逻辑。
4. V2-08 完成前，不得将“12 环境 30 分钟”标为通过；必须记录实际硬件、整机物理内存、CPU 和完整采样时长。
