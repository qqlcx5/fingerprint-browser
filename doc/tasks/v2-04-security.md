# V2-04 账号安全与 2SV 支撑

> 目标：提供 TikTok Shop 账号安全运营状态和可选 TOTP 管理，不替代平台验证。
> 依赖：V2-01、V2-02。
> 可写路径：`src/main/security/**`、`doc/tasks/v2-04-security.md`
> 禁止：修改现有代理/启动器/界面目录；需要接线时在任务末尾记录，由协调者处理。

## 任务清单

- [ ] T1 创建安全状态服务，读取和更新 2SV 启用状态、验证方式数量、手机号绑定状态、登录提醒状态、最近安全检查时间与待办；所有字段均为操作者手工确认状态。
- [ ] T2 实现可选 TOTP 密钥存储：默认关闭；启用、读取和删除均要求操作系统安全存储可用及重新认证；SQLite 只保存引用。
- [ ] T3 实现 TOTP 动态码生成和内存清理；禁止复制到剪贴板、禁止写日志、崩溃报告或导出文件；密钥不可用时返回可恢复错误。
- [ ] T4 在环境删除、清除本地数据和解除 TOTP 管理时销毁密钥；写入不含秘密内容的审计事件。
- [ ] T5 编写安全测试：默认无密钥、加密引用、导出脱敏、删除销毁、系统安全存储不可用时拒绝启用。

## 验收

- 仅主进程能取得动态验证码；渲染进程、SQLite、日志和导出文件均不能读到 TOTP 密钥。
- 所有密钥清除路径是幂等的。
- 不实现自动填写验证码、自动登录或对平台重新验证的规避。
