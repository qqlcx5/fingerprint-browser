# V2-06 环境编排与生命周期

> 目标：将代理绑定验证、Profile 启动、安全待办和审计串成唯一的环境生命周期。
> 依赖：V2-02、V2-03、V2-04、V2-05。
> 可写路径：`src/main/envManager/**`、`doc/tasks/v2-06-env-service.md`
> 禁止：修改 DB、代理、Profile、共享契约和界面目录；接线需求记录给协调者。

## 任务清单

- [x] T1 更新环境创建/编辑流程：要求业务环境有已验证代理绑定，保存站点、店铺标识、角色备注和安全状态；运行中环境拒绝修改绑定和配置。
- [x] T2 实现启动编排：内核就绪 -> 读取绑定 -> 验证固定出口 IP -> 检查站点/国家警告 -> 创建独立 Profile -> 发布运行状态。出口变化或验证失败必须在创建上下文前返回。
- [x] T3 实现显式重绑定流程：接收代理预检提交和变更原因，更新绑定与配置建议，写审计事件；禁止启动流程隐式改写出口 IP。
- [ ] T4 集成安全待办：启动成功后返回 2SV、手机号、登录提醒和重新验证待办；仅提示，不替代或自动完成平台流程。
- [ ] T5 更新环境列表、详情、导入导出与清除数据服务，覆盖 V2 字段和敏感数据排除；补端到端测试。服务实现已完成，仍需 V2 专项 E2E。

## 验收

- 出口 IP 不匹配时，浏览器上下文未创建且环境回到 `idle`。
- 完成重绑定后，旧/新出口 IP、原因和时间可审计。
- 环境列表可读取站点、店铺、角色、安全状态与验证时间；导出不泄露秘密。
