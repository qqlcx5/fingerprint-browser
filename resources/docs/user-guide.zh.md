# Fingerprint Browser 用户须知

> 版本 1.0.0 · 本文档随应用分发（resources/docs/），亦可在项目仓库 doc/ 目录查阅。

Fingerprint Browser 是一款桌面端多账号浏览器管理工具，面向电商客服、社媒运营等
合法多账号场景。核心能力：**账号环境隔离 + 独立代理 IP 绑定 + 轻量指纹差异化**。

## 1. 快速上手

1. **首次启动**：应用自动检测浏览器内核。内核缺失时会进入下载页（约 150–300MB，
   要求磁盘剩余空间 ≥ 2GB），下载失败可直接重试。
2. **创建环境**：点击"创建环境"，填写名称与备注；可选配置代理
   （HTTP / HTTPS / SOCKS5，支持账号密码认证）。
3. **测试连接**：代理表单中的"测试连接"会经代理请求出口检测接口，
   返回出口 IP、国家、延迟，四类错误（认证 / 超时 / DNS / 协议）均有明确提示。
4. **启动环境**：每个环境打开一个独立的浏览器窗口；**关闭该窗口即停止该环境**，
   登录态与浏览数据随之落盘保留。
5. **不配代理**：不配置代理的环境以直连方式启动，列表中标注"直连"。

## 2. 指纹策略（两段式）

- **核心指纹**（UA、平台、屏幕、WebGL、硬件并发数、设备内存等）在创建环境时
  按当时代理出口地区生成一次，**此后永久只读**，任何流程不会改写。
- **对齐字段**（时区、语言、地理位置）跟随代理。更换代理且出口国家变化时，
  应用会弹窗提示"地区已从 A 变为 B"：
  - 点"确认"：仅更新时区/语言/地理位置，核心指纹保持不变；
  - 点"取消"：保持原对齐字段直接启动。

## 3. 数据与隐私

- 所有数据仅存本机用户数据目录，**不采集、不上传**您的浏览数据：
  - 环境数据库：`userData/data/envs.db`
  - 环境数据（登录态/Cookie/下载）：`userData/envs/{环境}/`
  - 浏览器内核：`userData/chromium/{版本}/`
  - 日志：`userData/logs/`
- **卸载应用不会删除用户数据**（重装后登录态仍在）。
- 需要彻底清除时，使用应用内设置区的"**彻底清除数据**"按钮（二次确认后执行，
  清除环境数据；内核与日志保留）。代理密码经系统安全加密（Keychain / DPAPI）存储；
  系统加密不可用时降级为机器级混淆存储并明确提示。

## 4. 浏览器内核与升级

- 内核为 Playwright 管理的 Chromium，版本全局锁定，所有环境共享一份。
- **升级内核** = 随应用版本升级 playwright-core 并重新回归测试，应用内无手动升级入口。
- **升级须知**：核心指纹固定意味着内核升级后，旧环境的 UA 版本号可能与新内核
  实际版本存在**不一致窗口**（UA 中的 Chromium 版本落后于内核真实版本）。
  该窗口期属预期行为，对指纹稳定性无影响；如需刷新 UA，请新建环境。

## 5. 已知边界（使用前必读）

1. **指纹为 JS 层注入**：可防 FingerprintJS 级别的常规指纹采集，
   **不承诺对抗深度风控**（如 Cloudflare、银行级风控）。
2. **同机多环境硬件指纹相似**：同一台机器上多个环境的底层硬件特征天然相近，
   平台严格风控下仍存在被关联的风险。
3. **内核版本需定期随应用升级**：Chromium 版本由 Playwright 锁定，
   请保持应用为最新版本。
4. **UA 版本号滞后窗口**：见第 4 节升级说明。

## 6. 故障排查

| 现象 | 说明 |
|---|---|
| 提示"数据库曾损坏，已自动重建" | 环境库文件损坏时应用自动备份为 `.bak` 并重建空库，环境列表为空属预期，需重新创建环境 |
| 通知栏提示某环境崩溃 | 该环境状态已回滚为空闲，其他环境不受影响；退出码已记录到日志（userData/logs/） |
| 应用上次异常退出 | 启动时自动清理残留的孤儿浏览器进程，无需干预 |
| 代理测试失败 | 按提示区分：认证失败（检查账号密码）／连接超时（检查服务商与本机网络）／DNS 失败（检查代理主机名）／协议错误（检查代理类型选择） |
